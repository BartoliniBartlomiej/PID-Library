Detailed Description

Manual clock for testing and simulation.

This clock allows manual control of time progression, making it ideal for unit tests and deterministic simulations.

Example:

ManualClock clock;
clock.advance(std::chrono::milliseconds(100));
auto t = clock.now(); // Returns time advanced by 100ms
